Use your own MATLAB plot

The MATLAB export helper writes the x, y, and z data from one numeric Cartesian surface to JSON. Load that file using the control above, or include it in your website.

export_surface_for_website(ax, "my-surface.json")

For MATLAB R2026a and later, supported figures can also be exported directly to interactive HTML:

exportgraphics(fig, "my-interactive-plot.html")

That HTML can be embedded in a website. Built-in rotate, zoom, and pan are supported for appropriate axes; custom callbacks and MATLAB calculations do not run in the exported figure. This JSON viewer supports one rectangular surface; it does not reproduce every MATLAB figure type or formatting choice.
